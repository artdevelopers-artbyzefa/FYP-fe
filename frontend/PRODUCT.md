# Product

## Register

product

## Users

Faculty supervisors, committee members, students, FYP Office In-charge, and FYP Office Assistant — all interacting with FYP evaluation workflows in a university setting.

## Product Purpose

CUI DIMS (Departmental FYP Management System) manages Final Year Project workflows: group formation, supervisor allocation, proposal review, milestone evaluations, and result publishing across multiple phases.

## Brand Personality

Precise, Authoritative, Clean

## Anti-references

Generic AI-generated UIs — over-decorated, popup-heavy, inconsistent, templated dashboards with no attention to state.

## Design Principles

- **Tool over decoration.** Every element earns its place by serving a task or decision.
- **State transparency.** Loading, empty, error, success — never leave the user guessing.
- **Role-fit surfaces.** Each portal (student, faculty, office) matches its user's mental model, not a generic dashboard template.
- **Consistency is trust.** Same component vocabulary, same interaction patterns, screen to screen.

## Accessibility & Inclusion

WCAG 2.1 AA minimum. Keyboard-navigable forms, sufficient color contrast, focus indicators, reduced motion support.
